## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed calendar.svelte TypeScript union type complexity error**
- **Found during:** Task 2 (npm run check verification)
- **Issue:** shadcn-svelte@1.2.3 generates calendar.svelte using `WithoutChildrenOrChild<CalendarPrimitive.RootProps>` where `RootProps` is a large discriminated union. TypeScript reports "Expression produces a union type that is too complex to represent" and "Property 'type' is missing"
- **Fix:** Replaced the complex union type with an explicit `Record<string, unknown>` intersection type that enumerates only the needed props with concrete types. Added `type = "single"` default. Added `{type}` prop pass-through to `<CalendarPrimitive.Root>`.
- **Files modified:** `src/lib/components/ui/calendar/calendar.svelte`
- **Commit:** 812d3bd

**2. [Rule 3 - Deviation] shadcn-svelte init required manual approach**
- **Found during:** Task 1
- **Issue:** `npx shadcn-svelte@latest init` has no `--yes` flag and cannot run non-interactively
- **Fix:** Created `components.json` manually with the spec'd config, then used `npx shadcn-svelte@latest add ... --yes` for components (which does support `-y` flag)
- **Impact:** Zero — identical output to interactive init

**3. [Rule 2 - Missing dep] tailwind-merge not installed**
- **Found during:** Task 1 (writing src/lib/utils.ts)
- **Issue:** nova style installs `tailwind-variants` but not `tailwind-merge`. Standard `cn()` helper requires `tailwind-merge` for conflict resolution
- **Fix:** `npm install tailwind-merge` (added to dependencies)
- **Files modified:** package.json, package-lock.json
