## Decisions Made

- bits-ui Select requires `type="single"` to resolve TypeScript union ambiguity between SelectSingleRootProps (string) and SelectMultipleRootProps (string[]) — without it, `value: string` fails type check
- `Select.Value` not exported by this shadcn-svelte version — selected label displayed via `$derived` looking up `options.find(o => o.value === value)?.label`
- AdminLayout glow uses `padding: 9px 12px 9px {isActive ? '10px' : '12px'}` (4-value shorthand) to keep padding-right independent while adjusting padding-left for border compensation
