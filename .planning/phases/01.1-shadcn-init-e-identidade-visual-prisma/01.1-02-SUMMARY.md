# Phase 01.1 Plan 02: Widget Migration to shadcn Primitives Summary

**One-liner:** Migrated ConfirmDialog to bits-ui Dialog.Root bind:open, StatusBadge to shadcn Badge with :global() CSS, and Pagination to shadcn Button variant=outline — all public APIs preserved.

## What Was Built

Three shared widgets migrated from native HTML elements to shadcn/bits-ui primitives while keeping their public prop interfaces completely unchanged:

1. **ConfirmDialog** — replaced native `<dialog>` + `showModal()/$effect` lifecycle with declarative `Dialog.Root bind:open`. The bits-ui Dialog manages focus trap, backdrop, and Escape handling internally. Action buttons remain as native HTML inside Dialog.Content for parent-controlled close behavior.

2. **StatusBadge** — replaced `<span class="status-badge">` with shadcn `Badge variant="outline"`. Dynamic colors via `style` attribute (15-entry STATUS_MAP preserved). CSS classes use `:global()` wrapper and `-global-` keyframe prefix to escape Svelte's component scope since Badge renders its own element.

3. **Pagination** — replaced native `<button type="button">` with shadcn `Button variant="outline" size="icon"` for prev/next controls.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed CSS scoping for StatusBadge classes**
- **Found during:** Task 2
- **Issue:** Svelte's scoped CSS only applies to elements rendered in the component's own template. Badge renders `<span>` in its own template (badge.svelte), so `.status-badge` classes defined in StatusBadge.svelte would not match — Svelte adds component-specific hash attributes for scoping.
- **Fix:** Changed `.status-badge` and `.status-badge--med` to `:global(.status-badge)` and `:global(.status-badge--med)`. Changed `@keyframes med-pulse` to `@keyframes -global-med-pulse` so the animation is accessible from global CSS.
- **Files modified:** src/app/shared/widgets/StatusBadge.svelte
- **Commit:** 7750ba5
